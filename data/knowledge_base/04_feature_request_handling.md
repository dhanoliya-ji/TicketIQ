# Feature Request Handling

## What support should do
Never promise a delivery date for a requested feature. Support records the
request, links it to the customer account so that demand can be counted, and
tells the customer that it has been logged.

## Wording to use
Thank the customer for the idea, restate the request in one sentence so they
can see it was understood, and explain that the product team reviews logged
requests every month.

## Requests that already exist
If the capability already exists, point the customer at the exact settings page
instead of logging a duplicate request. A surprising number of requests are
really discoverability problems.

## Prioritisation signals
Enterprise customers and requests logged by more than 20 accounts are reviewed
first. A request from a customer whose renewal is within 60 days is flagged for
the account manager as well.

## Never escalate a feature request as an incident
A missing feature is not an outage. Feature requests are handled on the normal
queue even when the customer is on the enterprise tier.
